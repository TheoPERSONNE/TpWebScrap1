# TpWebScrap1

Dans main.py, le script effectue le scraping et génère des fichiers HTML 
par catégorie pour afficher les données extraites.
Il manque la catégorie "Teck".

Le fichier mainTerminal.py permet de lancer l'application depuis le terminal et de 
récupérer l'ensemble des articles des différentes catégories.

La page index.html (placée à la racine du projet) contient une barre de navigation 
qui redirige vers chaque fichier HTML généré pour les différentes catégories d’articles.
